\begin{frame}{What we built}
  \begin{columns}[T]
    \begin{column}{0.55\textwidth}
      \textbf{Book:} 16 trades, 3 counterparties (A/B/C) \\
      8 equity TRS, 4 bond forwards, 4 bond TRS \\
      37 equities (US + Tokyo) + USDJPY

      \vspace{6pt}
      \textbf{Engine:} full Monte Carlo, real data throughout
      \begin{itemize}
        \item Equities/FX: correlated GBM, real 3y realised vols and correlations
        \item USD rates: one-factor Hull-White, swaption-calibrated mean reversion, realised long-end vol
        \item JPY rates: a second Hull-White factor (real JPY OIS curve)
        \item Latin Hypercube sampling, common random numbers throughout
      \end{itemize}
    \end{column}
    \begin{column}{0.45\textwidth}
      \textbf{Exposure definition (the brief):}
      \[ \max\big(V(t{+}10\text{bd}) - V(t{-}1\text{bd}),\,0\big) \]
      signed prior-day VM, no IM/threshold, netted per counterparty

      \vspace{10pt}
      \textbf{Deliverables:} 77-page report, this deck, an Excel parametric-benchmark workbook, 168 automated regression tests
    \end{column}
  \end{columns}
\end{frame}

% ---------------------------------------------------------------- sampling & DV01
\begin{frame}{Latin Hypercube: where it helps, and a genuine extension}
  \begin{columns}[T]
    \begin{column}{0.55\textwidth}
      \includegraphics[width=\linewidth]{figures/fig_sampling_greeks.pdf}
    \end{column}
    \begin{column}{0.45\textwidth}
      \small
      \textbf{Base measures (Section 5.4):} Latin Hypercube is the best of 5 schemes tested.

      \textbf{Greeks noise:} mixed. LHS cuts noise on EE deltas (15--85\%) but not consistently on tail-quantile (PFE99) deltas.

      \textbf{New: LHS \emph{as} the sensitivity.} In one-factor Hull-White, $r(t)=x(t)+\alpha(t)$: the simulated $x(t)$ is unchanged by a curve bump. So a rate Greek is a closed-form shift of the \emph{same} simulated paths -- no resimulation. Validated to $10^{-15}$ relative precision against a true resimulation.
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{DV01 via a Jacobian: bump the curve, not just the zero rate}
  \begin{columns}[T]
    \begin{column}{0.55\textwidth}
      \includegraphics[width=\linewidth]{figures/fig_dv01_compare.pdf}
    \end{column}
    \begin{column}{0.45\textwidth}
      \small
      Old method: bump the \emph{fitted} zero curve at 8 hand-picked tenors.

      New method: bump the curve's own $\sim$45 native construction pillars (SOFR futures + Bloomberg long end), grouped into the same 8 buckets -- the real par-instrument sensitivity.

      \textbf{Finding:} the 30y bucket carries 82\% of portfolio DV01 (new) vs.\ 54\% (old) -- the old grid was smearing the 20--50y risk, where the 2049 bond forward actually lives, into the 10y bucket. Bucket sums match the parallel bump to within 0.1\% either way.
    \end{column}
  \end{columns}
\end{frame}

      \small
      \textbf{Why we build this in detail:} the value is the sensitivity chain (CVA01, rating table, SA-CVA weighted sensitivities), not the headline number.

      \textbf{New: KVA.} $K(t) = 8\%\times\text{RW}\times\alpha\times\text{EPE}(t)$, discounted, scaled by an assumed cost of capital (8/10/12\% swept, none given).

      At 10\% CoC: KVA \$22.4k (close-out) / \$470k (level) -- larger than CVA (\$11.7k / \$247k) because it scales the whole EPE profile, not a small IG default probability. Explicitly illustrative.

% ---------------------------------------------------------------- excel benchmark
\begin{frame}{Independent parametric benchmarks (Excel)}
  \small
  A separate, formula-only Excel workbook checks the engine against a hand calculator, using only public data:
  \begin{columns}[T]
    \begin{column}{0.48\textwidth}
      \begin{itemize}
        \item \textbf{Equity/FX vol:} \texttt{=STDEV(LN(Pt/Pt-1))*SQRT(252)} on raw yfinance closes matches the calibrated model vol to $\sim$0.1\%.
        \item \textbf{Rate vol:} same idea on FRED Treasury yields; the closed-form Hull-White formula $\sigma(1-e^{-aT})/(aT)$ lands within 5--10\% of realised at the fitted tenors.
      \end{itemize}
    \end{column}
    \begin{column}{0.48\textwidth}
      \begin{itemize}
        \item \textbf{Simulation cross-check:} analytic $\text{vol}\times\sqrt{T}$ vs.\ the standard deviation actually measured across 5,000 simulated scenarios: matches to 1--2\%.
        \item \textbf{Vega bump:} bumping a USD name's vol $\pm1\%$, the Monte Carlo vega of a simple ATM position matches the closed-form (undiscounted) Black vega to $\sim$7\%.
      \end{itemize}
    \end{column}
  \end{columns}
  \vspace{6pt}
  \textcolor{grey}{\small \texttt{docs/Capitolis\_CCR\_Parametric\_Benchmarks.xlsx} -- every number is a live formula, not a pasted value.}
\end{frame}
